# 📚 Documentação — Chegaê

Esta pasta reúne os documentos do projeto **Chegô**, agente de atendimento ao cliente desenvolvido para a plataforma fictícia **Chegaê**.

Os arquivos apresentam o contexto do projeto, as regras definidas para o atendimento, a construção do System Prompt, a arquitetura proposta e os resultados observados nas simulações realizadas no ChatGPT.

## Documentos

| Arquivo | Descrição |
|---|---|
| `01-visao-geral.md` | Contexto, objetivos e escopo do projeto |
| `02-arquitetura-do-agente.md` | Organização e fluxo de funcionamento do agente |
| `03-regras-de-negocio.md` | Diretrizes e limites definidos para o atendimento |
| `04-construcao-do-prompt.md` | Estrutura e desenvolvimento do System Prompt |
| `05-testes-e-resultados.md` | Cenários simulados e resultados observados |
| `06-estudo-de-caso.md` | Problema abordado e decisões tomadas durante o desenvolvimento |

## Objetivo

Registrar o processo de desenvolvimento do Chegô, incluindo as instruções utilizadas, as regras estabelecidas e o comportamento observado durante as simulações.

**Status:** Protótipo desenvolvido com Engenharia de Prompt e experimentado no ChatGPT, sem integração técnica com sistemas externos.
